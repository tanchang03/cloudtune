# CloudTune 云韵音乐 · 需求分析与产品设计

> 版本 v0.1（评审稿） · 2026-09-23
> 定位：一个「不下载、不搬家」的跨云盘音乐播放器
> 形态：Flutter 全平台客户端（Android / iOS / macOS / Windows / Linux，Web 降级）

---

## 1. 一句话定义

把你散落在**夸克网盘、阿里云盘、百度网盘**里的音乐文件，聚合成一个统一的音乐库，
**在线直连播放**，支持**随机播放**和**喜欢收藏**，不用把歌下载到本地，也不用手动整理目录。

---

## 2. 用户与场景

### 2.1 目标用户

| 用户类型 | 特征 | 核心痛点 |
|---|---|---|
| 网盘囤歌党 | 多年积累，歌散落在多个网盘、多个目录 | 找歌难、听歌要下载、换设备就要重来 |
| 多网盘用户 | 夸克放一部分、阿里放一部分、百度放老资源 | 要在三个 App 之间来回切 |
| 桌面端用户 | 上班/在家用电脑听歌 | 网盘官方客户端没有播放器体验 |

### 2.2 核心场景

1. **首次接入**：打开 App → 逐个授权网盘账号 → 一键全盘扫描 → 几分钟后得到完整音乐库。
2. **随手听**：打开 App → 点「随机播放」→ 开始听，遇到喜欢的点❤。
3. **找歌**：搜索「周杰伦」→ 跨三个网盘一起出结果 → 点开即播。
4. **跨设备**：电脑上收藏的歌，手机上也能看到（收藏本地为主 + 可选导出同步）。

## 3. 功能清单与优先级

优先级说明：**P0 = MVP 必须有**，**P1 = 首个正式版要有**，**P2 = 后续迭代**。

### 3.1 账号与授权（P0）

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| A1 | 夸克账号授权 | 走夸克开放平台 OAuth（详见审计报告，接入方式待拍板） | P0 |
| A2 | 阿里云盘授权 | 标准 OAuth2.0，scope：`user:base` + `file:all:read` | P0 |
| A3 | 百度网盘授权 | 标准 OAuth2.0（授权码模式） | P1 |
| A4 | Token 安全存储 | 系统钥匙串 / Keystore，禁止明文落盘与打日志 | P0 |
| A5 | Token 自动续期 | refresh_token 静默刷新，失败才提示重新授权 | P0 |
| A6 | 多账号并存 | 同一网盘可加多个账号，可单独启用/停用 | P1 |
| A7 | 账号解绑 | 清除本地 token 与索引数据 | P0 |

### 3.2 音乐库遍历与搜索（P0）

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| B1 | 全盘递归扫描 | 从根目录递归遍历，识别音乐文件 | P0 |
| B2 | 音乐文件识别 | 扩展名白名单：`mp3 flac m4a aac wav ape ogg wma opus`；可选按大小过滤 | P0 |
| B3 | 增量扫描 | 记录每个目录的扫描游标，二次扫描只拉变化 | P0 |
| B4 | 扫描进度可视化 | 目录数 / 文件数 / 已发现歌曲数，可暂停、可继续 | P0 |
| B5 | 后台扫描 | 切到后台/锁屏继续扫（移动端） | P1 |
| B6 | 跨网盘统一搜索 | 一个关键词，并发查所有已授权网盘 | P0 |
| B7 | 指定目录扫描 | 只扫用户选的目录，跳过视频/文档目录 | P1 |
| B8 | 元数据解析 | 从 ID3/FLAC tag 读标题、艺术家、专辑、封面；读不到则解析文件名 | P1 |
| B9 | 去重 | 同名同大小同网盘视为重复；跨网盘可选合并展示 | P2 |

> 关于 B1 的**技术前提**：夸克开放接口未提供「列目录」能力，只能靠搜索接口分页遍历（详见审计报告 §3.2），
> 因此 B1 在夸克侧是「分类/分页搜索式遍历」，而非传统 `list_dir` 递归。这是本产品最大的技术不确定性。

### 3.3 播放（P0）

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| C1 | 在线直连播放 | 播放前实时换取直链，边下边播，不落地整首 | P0 |
| C2 | 随机播放 | 洗牌队列（shuffle bag），避免短期内重复同一首 | P0 |
| C3 | 播放控制 | 播放/暂停、上一首/下一首、进度拖动、音量 | P0 |
| C4 | 播放模式 | 随机 / 顺序 / 单曲循环 / 列表循环 | P0 |
| C5 | 直链过期自愈 | 直链失效（阿里云盘 15 分钟）自动重新获取并续播 | P0 |
| C6 | 后台播放 | 锁屏控制、通知栏控制、耳机线控（移动端） | P1 |
| C7 | 播放历史 | 最近播放列表，可清空 | P1 |
| C8 | 桌面快捷键 | 空格播放/暂停、方向键切歌（桌面端） | P1 |
| C9 | 歌词 | 同目录 `.lrc` 文件自动加载 | P2 |
| C10 | 可选本地缓存 | 用户主动「缓存到本地」离线听 | P2 |
| C11 | 均衡器 / 倍速 | 播放增强 | P2 |
| C12 | **可播性预判与标记** | 扫描时按文件大小预判（夸克实测 >~50MB 无法取直链），列表与播放页对超限曲目标注「不可在线播放」，避免用户点了播不出来 | **P0** |
| C13 | **超限降级策略** | 超限曲目：明确提示原因（网盘侧限制）+ 提供「本地缓存后播放」入口（P2 实装缓存） | P1 |

> C12/C13 来自 PoC 实测：夸克存在 ~50MB 单文件体积上限，当前音乐库仅 **53.8%** 曲目可在线播放。
> 详见 `03-设计审计与风险评估.md` §7.2。

### 3.4 收藏（P0）

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| D1 | 一键喜欢 | 播放页/列表页点❤，立即生效 | P0 |
| D2 | 喜欢列表 | 独立 Tab，可按网盘/时间筛选 | P0 |
| D3 | 收藏持久化 | 本地数据库，卸载重装前可导出 | P0 |
| D4 | 收藏导出/导入 | JSON 导出，便于换机 | P1 |
| D5 | 收藏影响随机权重 | 喜欢的歌在随机中权重更高（可关闭） | P1 |
| D6 | 歌单 | 自建歌单，可增删排序 | P2 |

### 3.5 系统与设置（P1）

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| E1 | 深色/浅色主题 | 跟随系统 + 手动切换 | P1 |
| E2 | 并发与限流设置 | 用户可调扫描并发数，规避触发风控 | P1 |
| E3 | 网络代理设置 | 自定义 HTTP 代理（部分网盘直链有地域限制） | P2 |
| E4 | 数据统计 | 歌曲总数、各网盘占比、总时长 | P2 |

## 4. 页面结构与信息架构

```
CloudTune
├── 启动 / 引导
│   └── 首次启动引导（3 步：选网盘 → 授权 → 扫描）
├── 授权页（每个网盘一个授权入口）
│   ├── 夸克网盘（含接入方式说明）
│   ├── 阿里云盘
│   └── 百度网盘
├── 音乐库（首页）
│   ├── 搜索（跨网盘）
│   ├── 筛选：全部 / 喜欢 / 最近 / 按网盘
│   ├── 歌曲列表
│   └── 悬浮「随机播放」按钮
├── 扫描页
│   ├── 总进度 + 分网盘进度
│   ├── 实时发现歌曲数
│   └── 暂停 / 继续 / 取消
├── 播放器（全屏）
│   ├── 封面 + 标题 + 艺术家 + 来源角标
│   ├── 进度条 + 时间
│   ├── 控制区（上一首 / 播放暂停 / 下一首 / 模式）
│   ├── ❤ 喜欢
│   └── 播放队列
├── 喜欢（Tab）
├── 最近播放（Tab）
└── 设置
    ├── 账号管理（多账号、解绑）
    ├── 扫描设置（并发、目录范围、增量策略）
    ├── 播放设置（默认模式、随机权重）
    └── 数据（导出/导入/清空索引）
```

**导航形态**
- 移动端：底部 4 Tab（音乐库 / 喜欢 / 最近 / 设置）+ 底部常驻迷你播放条
- 桌面端：左侧导航栏 + 主区列表 + 底部播放条 + 支持迷你悬浮窗

## 5. 关键交互流程

### 5.1 首次接入流程

```
启动 → 引导页 → 选择网盘(可多选) → 逐个跳转授权页
      → 授权成功回调 → 展示账号信息(昵称/容量)
      → 「开始扫描」→ 扫描页(实时进度) → 完成 → 进入音乐库
```

### 5.2 随机播放流程

```
音乐库 → 点击「随机播放」
  → 取当前筛选范围内全部 Track → Fisher-Yates 洗牌成队列
  → 取队首 → 实时换取直链 → 起播
  → 播放中：❤ 收藏（立即写入本地库，不打断播放）
  → 播完 → 队列下一首 → 队列耗尽则重新洗牌（避免与上一轮首尾重复）
  → 直链失效 → 静默重取直链 → 从当前进度续播
```

### 5.3 扫描流程

```
扫描页 → 遍历根目录 → 并发受限地拉取目录/文件
  → 命中音乐扩展名 → 写入本地索引（含来源、路径、大小、修改时间）
  → 每 N 条批量落库 → 更新进度
  → 失败目录 → 记录到重试队列 → 退避重试 3 次
  → 全部完成 → 计算统计 → 提示「发现 XXX 首」
```

## 6. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 首次扫描 1 万文件量级应在 3～8 分钟内完成（受网盘限流约束）；列表滚动 60fps；已索引库打开即用，不发网络请求 |
| 可用性 | 单网盘接口异常不影响其他网盘；单曲播放失败自动跳下一首并提示 |
| 稳定性 | 直链过期、限流(429)、token 过期三类错误必须有自动恢复路径 |
| 安全 | token 存系统钥匙串；日志脱敏；不上传任何用户文件与播放记录到自建服务器 |
| 合规 | 纯客户端直连官方开放 API；不自建中转；不对外分享直链；不冒充官方应用 |
| 兼容 | Android 8+ / iOS 14+ / macOS 12+ / Windows 10+ / Linux(glibc 2.28+) / Web(仅浏览管理) |
| 可扩展 | 新增一家网盘只需实现一个 Adapter，不改上层 |

## 7. 明确不做（Out of Scope）

- ❌ 音乐**下载/分发**服务（不做外链、不做分享站）—— 触碰阿里云盘红线
- ❌ 在线音乐**搜索聚合**（不接第三方版权曲库）
- ❌ 网盘文件**上传/移动/删除**等写操作（MVP 阶段只读，避免误操作与权限风险）
- ❌ **破解/绕过**会员限制或加速下载
- ❌ 账号密码托管（只存 OAuth token，绝不存密码）

## 8. 里程碑规划

| 阶段 | 内容 | 交付判定 |
|---|---|---|
| M0 | Flutter 工程骨架、路由、主题、本地库(Drift)、SecureStorage | 能跑起来，能存一个假账号 |
| M1 | 夸克接入（授权 + 扫描 + 直链播放 + 收藏） | 夸克网盘能完整听歌（**风险最高，先打这个**） |
| M2 | 阿里云盘接入 | 两云盘可同时用 |
| M3 | 百度网盘接入 | 三云盘可同时用 |
| M4 | 平台打磨：后台播放、锁屏控制、桌面快捷键、迷你窗 | 各平台体验达标 |
| M5 | 增量扫描优化、元数据/封面、歌词、歌单 | 体验完善 |

> 排序理由：**先把不确定性最大的夸克打通**。如果夸克接不通，整个产品的价值主张要重新讨论，
> 这时还没投入阿里/百度的开发成本，损失最小。
